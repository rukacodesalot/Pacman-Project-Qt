# 🎮 Pacman Game (Qt/C++)

A Pacman-inspired desktop game developed in C++ using the Qt framework. The project demonstrates object-oriented programming, event-driven design, real-time game updates, and graphical user interface development.

## Features

* Keyboard-controlled Pacman movement
* Real-time game loop using Qt timers
* Pellet collection and score tracking
* Collision detection between Pacman, pellets, and enemy
* Bouncing ghost enemy AI
* Custom sprite rendering with Qt's painting system
* Boundary checking to keep characters within the game window

## Tech Stack

* C++
* Qt Framework
* Qt Creator
* Object-Oriented Programming (OOP)

## How to Play

1. Launch the game.
2. Use the arrow keys to move Pacman.
3. Collect pellets to increase your score.
4. Avoid colliding with the ghost enemy.
5. The game ends when Pacman touches the enemy.

## Learning Outcomes

This project strengthened my understanding of object-oriented programming, event handling, collision detection, game loops, GUI development, and software design using the Qt framework.
