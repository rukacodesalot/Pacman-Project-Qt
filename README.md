# 🎮 Pacman Game (Qt/C++)

A Pacman-inspired desktop game developed in C++ using the Qt framework. The project demonstrates object-oriented programming, event-driven design, collision detection, game state management, and multimedia integration.

## Features

* Keyboard-controlled Pacman movement
* Maze walls with collision detection
* Pellet collection and score tracking
* Lives system and level progression
* Enemy ghost AI with dynamic movement
* Start, pause, restart, and quit controls
* Win and Game Over states
* Background music using Qt Multimedia
* Custom graphics rendering with Qt Painter

## Tech Stack

* C++
* Qt Framework
* Qt Creator
* Qt Multimedia
* Object-Oriented Programming (OOP)

## Learning Outcomes

This project strengthened my understanding of GUI development, game loops, collision detection, event handling, object-oriented design, multimedia integration, and software architecture using the Qt framework.
